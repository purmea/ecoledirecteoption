# Wallet (PWA)

Site statique, 100 % côté client (aucun serveur, aucune donnée envoyée). Soldes modifiables, stockés dans le `localStorage` du téléphone.

## Utiliser sur iPhone
1. Héberger le dossier `larp-wallet/` (GitHub Pages, Netlify, Vercel… ou glisser-déposer sur netlify.com/drop).
2. Ouvrir l'URL dans **Safari** → bouton Partager → **Sur l'écran d'accueil**.
3. Lancer depuis l'icône : plein écran, comme une vraie app.

## Modifier les fonds
Toucher une crypto → **Modifier le solde** (quantité ou valeur en $/€). Réglages (bouton profil) : devise, prix en direct, remise à zéro.
